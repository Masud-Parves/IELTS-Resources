# IELTS Writing Task 2 — Double Question Essay Guide

> **Goal:** Band 7+ with one fixed structure you can remember under exam pressure.
> **Length:** minimum **260 words**, maximum **300 words**, target **about 280 words**.
> **Rule:** same 4 paragraphs every time. **Question 1 goes in BP1. Question 2 goes in BP2. Answer both directly.**
> **Ideas:** simple ideas from your topic-wise idea bank, developed well. **Give an opinion only where a question asks for one.**

---

## 1. The Memory Card (learn this first)

```text
SPLIT   Write Q1 and Q2 separately. Test each one:
        Must I choose a side? (yes/no, good/bad)  -> OPINION block
        Does it ask why / what / how?             -> LIST block

ORDER   Q1 = BP1. Q2 = BP2. Always the question's order.
LENGTH  260-300 words. Plan: 35 + 105 + 105 + 35 = 280.

INTRO   (30-40)    Paraphrase the situation.
                   [Answer to Q1], and [answer to Q2].

BODY    (90-120 each). Use the block that matches the question:

        LIST block      P  One of the main [reasons] for this is ...
        (2 ideas)       E  ..., so ...
                        X  For example, a ... who ..., and this ...
                        P  Another important [reason] is ...
                        E  ...; as a result, ...
                        L  Consequently, ...

        OPINION block   P  (As for whether ...,) I firmly believe that
        (1 clear side)     [answer] because [one reason].
                        E  When ..., ...
                        X  For instance, a ... who ..., which ...
                        R  Although some people argue that ..., [my side].
                        L  Therefore, ...

CONCL   (30-40)    In conclusion, [answer to Q1 in new words].
                   [Answer to Q2 in new words].
```

**You already know both blocks.** The List block is the P E X P E L paragraph from your Cause/Problem + Solution essay. The Opinion block is the P E X R L paragraph from your Agree/Disagree essay.

**The golden rule:** a double question is two small essays in one. If you answer both clearly and develop both, you have done the main job.

## 2. The Only Decision: List or Opinion?

### The 5-second test

Read each question on its own and ask:

| Test | If yes | It needs |
|---|---|---|
| **Must I choose a side?** *(yes or no, positive or negative, good or bad)* | **Opinion block** | One clear answer + one developed reason |
| **Does it ask me to name things?** *(why, what, how, in what ways)* | **List block** | Two ideas |

| Question words | Block | From your sheets |
|---|---|---|
| *Do you think …?* · *Is it important …?* · *Is this positive or negative?* · *Has this had …?* | **Opinion** | HEA-03, SOC-07, FAM-04, FAM-09 |
| *Why …?* · *What are the reasons …?* | **List** (reasons) | WRK-10, MED-15 |
| *What problems …?* | **List** (problems) | WRK-14, FAM-07 |
| *What other solutions …?* · *How can this be solved / achieved?* · *What measures …?* | **List** (solutions) | EDU-10, ENV-07, ENV-09 |
| *What other factors …?* · *What kinds of skills …?* · *In what ways …?* · *What benefits …?* | **List** (factors, skills, ways, benefits) | WRK-16, EDU-13, SOC-08, ENV-07 |

### ⭐ The three patterns

Every double question in your sheets is one of these three.

| Pattern | BP1 | BP2 | Questions in your sheets |
|---|---|---|---|
| **1. List + Opinion** | List block | Opinion block | EDU-17, TEC-03, WRK-05, FAM-01, FAM-04, MED-05, MED-12, MED-15 |
| **2. Opinion + List** | Opinion block | List block | EDU-10, EDU-13, ENV-09, HEA-03, WRK-19, BUS-16, CRI-03, CRI-07, FAM-09, MED-03, SOC-07 |
| **3. List + List** | List block | List block | EDU-06, ENV-07, WRK-10, WRK-14, WRK-16, FAM-07, SOC-08 |

### ⭐ The "do you think" trap

The words *do you think* do **not** always ask for your opinion. **Use the first word of the question, not the words in the middle.**

| Question | The trap | Block |
|---|---|---|
| **WRK-14:** *Why do you think that is?* | It only asks for reasons | **List** |
| **EDU-06:** *What do you think the role of a parent should be …?* | You must name things, not choose a side | **List** |
| **MED-15:** *Do you think this is a good thing?* | None. You must choose a side | **Opinion** |
| **FAM-01:** *Is this a negative or positive development?* | There is no *do you think*, but you must still choose | **Opinion** |

### ⭐ The "other" trap

If Q2 says **other**, your ideas must be **different** from the one in the question.

| Question | ❌ Wrong | ✅ Right |
|---|---|---|
| **HEA-03:** school sport … *What other solutions can you suggest?* | More PE lessons, a new sports hall | Healthier school food, better habits at home |
| **WRK-19:** income … *What other factors should be considered?* | A high salary, bonuses | Job satisfaction, career growth |
| **WRK-16:** promotion … *What other factors influence people to work hard?* | A better job title | Pride in the work, fear of losing a job |

## 3. Know the Question Type (30 seconds)

| Do **not** use this guide when the question asks | Why | From your sheets |
|---|---|---|
| *What are the causes / problems? What are the solutions?* | Use the [Cause/Problem + Solution guide](IELTS_Cause_Problem_Solution_Essay_Guide.md) | HEA-09, TOU-02 |
| *What are the advantages? Do you think they outweigh the disadvantages?* | Use the [Advantages & Disadvantages guide](IELTS_Advantages_Disadvantages_Essay_Guide.md). The question is about both sides | FOO-12, FAM-08, TEC-05 |
| *What are the advantages? Are there any disadvantages?* | Same guide | COM-13 |
| *To what extent do you agree or disagree?* | Use the [Agree/Disagree guide](IELTS_Agree_Disagree_Essay_Guide.md) | |
| *Discuss both views and give your opinion.* | Use the [Discuss Both Views guide](IELTS_Discuss_Both_Views_Essay_Guide.md) | |

> **Your sheets label TEC-05 as a two-part question,** but it has the same shape as FOO-12 and FAM-08, so this guide sends it to the Advantages & Disadvantages guide.

### Do not mix up your five guides

| | Adv / Disadv | Agree / Disagree | Discuss Both Views | Cause/Problem + Solution | **This guide** |
|---|---|---|---|---|---|
| **Opinion** | Only if asked | Yes | Yes | Only if asked | **Only in the question that asks** |
| **Intro, sentence 2** | *Although …* | *I completely agree …* | *I completely support the latter …* | *This is mainly because …, but …* | ***[Answer 1], and [answer 2].*** |
| **BP1** | 2 advantages | Idea 1 | The other view | 2 causes or problems | **Answer to Q1** |
| **BP2** | 2 disadvantages | Idea 2 | My view | 2 solutions | **Answer to Q2** |
| **Body shape** | 7 sentences | P E E X L · P E X R L | P E E X L · P E X R L | P E X P E L, both | **List: P E X P E L · Opinion: P E X R L** |
| **R sentence** | No | BP2 | BP2 | No | **Only in the Opinion block** |
| **Conclusion** | *While …* | *I firmly believe …* | *While … I firmly believe …* | *In conclusion, [causes]. [Solutions] would …* | ***In conclusion, [answer 1]. [Answer 2].*** |
| **Total words** | 330–360 | 300–320 | 260–299 | 260–300 | **260–300** |

## 4. Task Response — What the Examiner Wants

| # | Job | Where you do it | If you miss it |
|---|---|---|---|
| 1 | Answer **Q1** directly | Intro, BP1, conclusion | Part of the question is not answered |
| 2 | Answer **Q2** directly | Intro, BP2, conclusion | Part of the question is not answered |
| 3 | **Develop** both answers with an explanation and an example | BP1 and BP2 | Your ideas stay as a list |
| 4 | Give **one clear side** wherever a question asks for an opinion | Intro, Opinion block, conclusion | Your position is unclear |
| 5 | Stay on the **exact** question | Every sentence | Your ideas lose focus |

**Give both questions similar space.** A long BP1 with two lines for Q2 leaves the second question underdeveloped. This is the most common way to lose marks in this essay.

**Answer the exact question.** MED-12 asks whether the **government should spend more money** on local films, not whether local films are good. BUS-16 asks how to recruit **sales staff**, not any staff. In ENV-07, *How can this be solved?* means the loss of beauty spots, not the benefits you wrote about in BP1.

### Choosing your side

Do not ask *"What do I truly believe?"* Ask:

> **Which answer gives me one simple reason that I can explain with an example?**

Then let Q2 help you. The question usually shows which answer flows best.

| If the question says | The easy answer | Why | From your sheets |
|---|---|---|---|
| *the **best** way / the **main** cause / the **most** valuable / an **effective** measure*, then asks for others | **No** | Q2 follows naturally: *not this one, but these others* | HEA-03, EDU-10, EDU-13, CRI-03, CRI-07 |
| *Is it **important**?*, then asks how | **Yes** | Q2 follows naturally: *it matters, and this is how* | ENV-09, SOC-07 |
| *Is this **positive or negative**?* | Whichever your reason supports | Choose one and keep it | FAM-01, FAM-04 |

### Banned phrases

| ❌ Never write | ✅ Write instead |
|---|---|
| *It helps, but it is not the best solution alone.* | *I firmly believe that this is not the best way because …* |
| *This is a largely negative development.* | *I firmly believe that this is a negative development.* |
| *It has both positive and negative sides.* | Choose one |
| *It depends on the situation.* | Choose one before you start |
| *This essay will explain why … and what …* | Give your real answers (Section 6) |

> **Naming other factors is not a partial opinion.** In WRK-19, you can firmly believe that money is important and then discuss other factors, because the question asks for them.

### Where *I* belongs

| Part | Use *I firmly believe*? |
|---|---|
| **Opinion block** | Yes. It opens the paragraph |
| **List block** | No. *One of the main reasons is …* is already a clear answer |
| **Introduction and conclusion** | Only if the essay has an Opinion block |
| **List + List essay** | Nowhere. No opinion was asked for |

## 5. The Fixed Structure

| Paragraph | Content | Sentences | Words |
|---|---|---|---|
| **Introduction** | a. Paraphrase the situation<br>b. Answer to Q1 + answer to Q2 | 2 | **30–40** |
| **Body Paragraph 1** | Answer to Q1 — List or Opinion block | 5 or 6 | **90–120** |
| **Body Paragraph 2** | Answer to Q2 — List or Opinion block | 5 or 6 | **90–120** |
| **Conclusion** | a. Answer to Q1 in new words<br>b. Answer to Q2 in new words | 2 | **30–40** |
| **Total** | | 14–16 | **260–300** (target about 280) |

### ⭐ The word plan: 35 + 105 + 105 + 35 = 280

| If you write | Total | Result |
|---|---|---|
| The minimum in every paragraph (30 + 90 + 90 + 30) | 240 | ❌ Too short |
| **The plan (35 + 105 + 105 + 35)** | **280** | ✅ Safe |
| The maximum in every paragraph (40 + 120 + 120 + 40) | 320 | ❌ Too long |

- **List block:** six sentences × about 18 words = 108.
- **Opinion block:** five sentences × about 21 words = 105.
- **Do not count every word in the exam.** In practice, find out how many lines 280 words fills in your handwriting.

> **This is your practice rule, not an IELTS rule.** IELTS has a 250-word minimum and no maximum. If you reach 305 words in the exam, do not cross out a good sentence in a hurry. Use that time to check your grammar.

### Why two ideas in a List block but one in an Opinion block?

- **List questions** usually ask for *reasons, problems, solutions* or *factors* (plural), so two ideas answer them fully.
- **Opinion questions** need one clear side. One reason, developed well, is enough.

> **Emergency exits.** If you can think of only one good idea for a List question, develop it with P E E X L. If you cannot think of an R sentence in an Opinion block, write a second Explain sentence. The paragraph is still complete.

### ⭐ The same answers run through the whole essay

The same answers appear in the introduction, the body and the conclusion, in the same order. Only the words change.

| FAM-04 | Q1: Reason 1 | Q1: Reason 2 | Q2: Opinion |
|---|---|---|---|
| **Introduction** | *modern life is busy* | *technology separates people* | *a negative development* |
| **Body paragraphs** | *the busy modern lifestyle* | *a separate digital world* | *harmful* |
| **Conclusion** | *daily schedules are crowded* | *digital devices keep relatives apart* | *damaging* |

## 6. Introduction Template

**Two sentences, 30–40 words.**

**a. Paraphrase the situation (~13–16 words)**

> *As …, …* · *Nowadays, …* · *A growing number of …* · *[Topic] is often suggested as …*

Change the words **and** the sentence order. Do not copy the question.

**b. Both answers in one sentence (~20–25 words)**

> **[Answer to Q1], and [answer to Q2].**

| Pattern | Formula | Example |
|---|---|---|
| **List + Opinion** | *This is mainly because [R1] and [R2], and I firmly believe that [answer].* | *This is mainly because modern life is busy and technology separates people, and I firmly believe that this is a negative development.* |
| **Opinion + List** | *I firmly believe that [answer], and [S1] and [S2] would work better.* | *I firmly believe that this is not the best way, and healthier school meals and better habits at home would work better.* |
| **List + List** | *This is mainly because [R1] and [R2], and this can lead to [P1] and [P2].* | *This is mainly because farming pays poorly and cities offer more jobs, and this movement can lead to overcrowded cities and ageing villages.* |

**Change only the words that do not fit the question.**

| Question | Sentence b |
|---|---|
| **EDU-17** (benefits + opinion) | *Community work teaches [B1] and [B2], and I firmly believe that it should be part of the curriculum.* |
| **WRK-19** (opinion + other factors) | *I firmly believe that money is an important factor, and [F1] and [F2] should also be considered.* |
| **SOC-08** (ways + why) | *History can be passed on through [W1] and [W2], and it matters because [R1] and [R2].* |

**Your opinion's reason stays out of the introduction.** There is no room for it in 40 words, so it opens your Opinion block instead.

| ❌ Avoid | Why | ✅ Better |
|---|---|---|
| *This essay will explain why this happens and what problems it causes.* | A memorised sentence with no idea in it | Name the real reasons and problems |
| *There are many reasons for this, and it is a bad thing.* | Says nothing | *This is mainly because modern life is busy and …* |
| *In my opinion, this is a serious problem.* in a List + List essay | Nobody asked | Leave it out |

## 7. The List Block — P E X P E L

> **General rules for every essay type:** see [IELTS_Body_Paragraph_Rules.md](IELTS_Body_Paragraph_Rules.md). If a sentence opener sounds unnatural in your essay, change it.

| # | Role | Safe starter | The question it answers |
|---|---|---|---|
| 1 | **P** Idea 1 | *One of the main [reasons] for this is that …* | What is my first answer? |
| 2 | **E** Explain | *…, so …* · *When …, …* | Why is it true? How does it happen? |
| 3 | **X** Example | *For example, a … who …, and this …* | Shows sentence 2 happening |
| 4 | **P** Idea 2 | *Another important [reason] is …* | What is my second answer? |
| 5 | **E** Explain | *…; as a result, …* · *…, which …* | Same question as sentence 2 |
| 6 | **L** Link | *Consequently, …* | What is the overall result? |

### Only one word changes: use the question's own word

| The question asks for | Sentence 1 | Sentence 4 |
|---|---|---|
| **Reasons** | *One of the main reasons for this is …* | *Another important reason is …* |
| **Problems** | *The most serious problem caused by this trend is …* | *Another problem is …* |
| **Benefits** | *One of the main benefits of this is …* | *Another important benefit is …* |
| **Factors, skills, ways** | *One important factor / skill / way is …* | *Another important factor / skill / way is …* |
| **Solutions** | *The most effective solution is for [who] to [do what].* | *In addition, [who] could [do what].* |

**Solutions need WHO + WHAT + HOW,** the same as in your [Cause/Problem + Solution guide](IELTS_Cause_Problem_Solution_Essay_Guide.md). End with *Together, these measures would …*. Use *should, could, can, would*, because solutions have not happened yet.

## 8. The Opinion Block — P E X R L

| # | Role | Safe starter | The question it answers |
|---|---|---|---|
| 1 | **P** Answer + reason | **In BP1:** *I firmly believe that [answer] because [reason].*<br>**In BP2:** *As for whether [question], I firmly believe that [answer] because [reason].* | What is my side, and why? |
| 2 | **E** Explain | *When …, …* | How does the reason work? |
| 3 | **X** Example | *For instance, a … who …, which …* | Shows sentence 2 happening |
| 4 | **R** Response | *Although some people argue that [other side], [my side].* | Why is my side stronger? |
| 5 | **L** Link | *Therefore, …* | Back to my answer |

**Use each example opener once.** The first body paragraph uses *For example*, and the second uses *For instance*, whichever block comes first.

### The R sentence

- Your side always goes **after the comma**.
- Never write *but* after *Although*.
- Give the other side **one clause only**.

| ❌ Wrong | ✅ Right |
|---|---|
| *Although diet matters, physical education keeps children active.* (Ends on the other side.) | *Although some people argue that physical education keeps children active, it cannot undo the effects of an unhealthy diet.* |

### ⭐ Build the bridge to the next paragraph

In an Opinion + List essay, your opinion should lead into your list. Essay B says diet matters more than sport, so its solutions are about food. The two paragraphs then connect without an extra linker.

### The Example rule — for both blocks

The example must show the Explain sentence right before it. **Point → Explain → Example is one chain.**

| ❌ Same topic, different idea | ✅ Shows the explanation |
|---|---|
| **E:** *Parents work long hours and children go to tuition.* **X:** *a teenager who plays online games may ignore their parents.* (E is about busy schedules, but X is about screens.) | **E:** the same sentence. **X:** *a father who returns home late may find that his son is still at a tuition class.* |

**The 5-second test:** read E and X together. If the same situation is not in both, change the example.

**Examples must be realistic, not fake facts.** Never invent a statistic, a study or an expert.

### Fixing the length

| Problem | Fix |
|---|---|
| **A body under 90 words** | Ask *"why?"* or *"what happens next?"*, and add that detail |
| **A body over 120 words** | Shorten the example. It should be one sentence, not a story |
| **Essay under 260 words** | Aim for about 105 in each body paragraph, not 90 |
| **Essay over 300 words** | Cut extra details and repeated ideas. **Never cut the explanation or the example** |

## 9. Sentence Variety and Linking Devices

### Sentence variety — the key to band 7 in Grammar

Most sentences should be about 15–25 words, and your example can reach about 30. You do not need every type in every paragraph.

| Type | Pattern | From the model essays |
|---|---|---|
| **Long simple** | *[long subject] + verb + object* | *Therefore, increasing school sport alone cannot be the most effective answer.* |
| **Compound** | *…, so … · …; as a result, …* | *They also have better schools and hospitals**; as a result,** parents may believe …* |
| **Complex** | *when / if / although / because / who / which* | ***When** relatives eat, talk and travel together, they learn to understand and support each other …* |
| **Compound-complex** | *a … who …, and this …* | *For example, a father **who** returns home late … may find that his son is still at a tuition class, **and** this means that they rarely eat together.* |
| **Verb+ing as subject** | *Increasing …, Adding …* + verb | ***Increasing** school sport alone **cannot be** …* |
| **Passive** | *be + past participle* | *More school sport **is often suggested** as an answer …* |

**Rules**
- **The example is never a short simple sentence.** Add *who / which / while / when*.
- **Accuracy comes first.** A correct compound sentence scores higher than a broken complex sentence. Use the structures you have practised.

### Linking devices — Coherence & Cohesion

| Job | Device | Where it goes |
|---|---|---|
| Join your two answers | *…, and …* | Intro sentence b |
| Move to the opinion question | *As for whether …, …* | Opinion block P in BP2 |
| Add a second idea | *Another important … is …* · *In addition, …* | List block Point 2 |
| Give an example | *For example, …* · *For instance, …* | X |
| Show a result | *…, so …* · *…; as a result, …* · *…, which …* | E, X |
| Answer the other side | *Although some people argue that …, …* | R |
| Close a paragraph | *Consequently, …* · *Therefore, …* · *Together, these measures would …* | L |
| Close the essay | *In conclusion, …* | Conclusion |

> ⚠️ **Use one linker in a sentence.** Never stack them (*~~Moreover, in addition,~~*), and do not start every sentence with one.

## 10. Conclusion Template

**Two sentences, 30–40 words.** One answer in each sentence. New words, same ideas, no new idea.

| Pattern | Sentence a | Sentence b |
|---|---|---|
| **List + Opinion** | *In conclusion, [situation] because [R1] and [R2].* | *I firmly believe that [answer] because [reason].* |
| **Opinion + List** | *In conclusion, I firmly believe that [answer] because [reason].* | *[S1] and [S2] would [result].* |
| **List + List** | *In conclusion, [situation] because [R1] and [R2].* | *However, this [P1] and [P2].* |

| ❌ Avoid | Why |
|---|---|
| Answering only Q2 | The examiner should see both answers one last time |
| *In conclusion, this is an important issue for society.* | Fits every question and answers nothing |
| *Governments should also …* (a new idea) | A new idea has no support, so leave it out |
| *I firmly believe …* in a List + List essay | An opinion was not asked for |
| Repeating your introduction word for word | Say the same meaning in new words |

## 11. Model Essays

### Model Essay A — List + Opinion

**Question (FAM-04):** *Nowadays, it seems that different generations within the family spend less time doing activities together. Why is that? Is it a positive or negative development?*

**5-minute plan**
- **Q1:** *Why is that?* names things → **List**: busy lifestyle → a father and a son at tuition · technology.
- **Q2:** *Positive or negative?* needs a side → **Opinion**: negative, because shared activities strengthen relationships → a teenager at dinner.
- **R:** video calls can connect generations.
- **Idea bank:** Chapter 08 Family → *The Generation Gap and Time Together*.

**Introduction** (35 words)
> Members of different generations in a family now seem to share fewer activities. This is mainly because modern life is busy and technology separates people, and I firmly believe that this is a negative development.

**Body Paragraph 1 — List block, reasons** (114 words)
> One of the main reasons for this is the **busy modern lifestyle**. Parents often work long hours, while children spend much of their time at school, in private tuition and doing homework. For example, a father who returns home late from the office may find that his son is still at a tuition class, and this means that they rarely eat together. Another important reason is technology, which has changed the way families spend their evenings. In the past, relatives gathered to watch the same television programme, whereas each member may now spend free time in a separate digital world. Consequently, a family can live in one home and still share very little time.

**Body Paragraph 2 — Opinion block** (106 words)
> As for whether this trend is positive or negative, I firmly believe that it is harmful because shared activities strengthen family relationships. When relatives eat, talk and travel together, they learn to understand and support each other, and children feel more secure and confident. For instance, a teenager who talks to their parents at dinner every evening is more likely to ask for help with a problem, which may stop it from becoming serious. Although some people argue that video calls can connect generations, a short call cannot replace the closeness of time spent together. Therefore, this loss of family time is clearly a negative development.

**Conclusion** (34 words)
> In conclusion, families share less time because daily schedules are crowded and digital devices keep relatives apart. I firmly believe that this change is damaging because it weakens the closest bonds in people's lives.

**Total: 289 words** ✅

### Model Essay B — Opinion + List

**Question (HEA-03):** *The amount of time spent on sport and exercise should be increased in schools in order to tackle the problem of overweight children. Do you think this is the best way to deal with the problem? What other solutions can you suggest?*

**5-minute plan**
- **Q1:** *Do you think …?* needs a side → **Opinion**: **No** (*best* + *other solutions*), because diet affects weight more → a child who plays football and drinks soft drinks.
- **Q2:** *What other solutions?* names things → **List**: **not** more sport. Schools improve food → a pupil who drinks water · parents build better habits.
- **R:** physical education keeps children active.
- **Idea bank:** Chapter 04 Health → *Children's Health, School Sport and Physical Education*.

**Introduction** (38 words)
> More school sport is often suggested as an answer to the rising number of overweight children. I firmly believe that this is not the best way, and healthier school meals and better habits at home would work better.

**Body Paragraph 1 — Opinion block** (109 words)
> I firmly believe that extra school sport is not the best way to tackle this problem because diet has a stronger effect on weight than exercise. When children regularly eat more calories than their bodies need, one extra hour of activity cannot balance them, so they continue to gain weight. For example, a child who plays football for an hour at school but drinks several cans of soft drink and eats fried snacks at home will still gain weight. Although some people argue that physical education keeps children active, it cannot undo the effects of an unhealthy diet. Therefore, increasing school sport alone cannot be the most effective answer.

**Body Paragraph 2 — List block, solutions** (113 words)
> The most effective alternative is for schools to improve the food that they provide. If schools offer healthy lunches, sell fruit instead of sweets and remove sugary drinks from vending machines, children will find healthy choices much easier. For instance, a pupil who can no longer buy a soft drink at break may start drinking water instead, which removes a large amount of sugar from their diet. In addition, parents could build better habits at home. When they prepare home-cooked meals and limit screen time, children eat fewer fried snacks and spend more time playing outside. Together, these measures would tackle the main causes of childhood obesity far more effectively than extra sport.

**Conclusion** (37 words)
> In conclusion, I firmly believe that adding more sport to the timetable is not the ideal answer because food matters more. Healthier school food and sensible routines at home would help children to reach a healthy weight.

**Total: 297 words** ✅

**Notice:**
- **The soft drink in BP1 returns in BP2.** The problem and the solution are the same situation, so the two paragraphs connect naturally.
- **The answer is clean.** The R sentence admits that sport keeps children active, but the essay never moves from *not the best way*.
- **Every solution is about something other than sport,** so the *other* trap is avoided.

### Model Essay C — List + List

**Question (WRK-10):** *In many developing countries, there is an increasing movement of workers from rural areas into the cities. Why do you think this happens? What problems can this cause?*

**5-minute plan**
- **Q1:** *Why …?* names things → **List** (*do you think* is the trap): poor farm incomes → a young farmer moves to Dhaka · better city opportunities.
- **Q2:** *What problems …?* names things → **List**: overcrowded cities → a garment worker in a slum · ageing villages.
- **No opinion and no *I*,** because neither question asks you to choose a side.
- **Idea bank:** Chapter 06 Work → *Migration for Work and Brain Drain*.

**Introduction** (37 words)
> A growing number of workers in developing nations are leaving villages for urban areas. This is mainly because farming pays poorly and cities offer more jobs, and this movement can lead to overcrowded cities and ageing villages.

**Body Paragraph 1 — List block, reasons** (115 words)
> One of the main reasons for this movement is that farming provides **low and uncertain incomes**. Rural areas offer few other jobs, so a poor harvest can leave a whole family without enough money. For example, a young farmer who earns very little may move to Dhaka to work in a garment factory, and a regular wage can help the family escape poverty. Another important reason is that cities offer far more jobs in offices, shops and services. They also have better schools and hospitals; as a result, parents may believe that their children will have a brighter future there. Consequently, many rural families see the city as the best way to improve their lives.

**Body Paragraph 2 — List block, problems** (103 words)
> The most serious problem caused by this trend is that cities become overcrowded. Housing becomes expensive as more people arrive, so many newcomers have no choice but to live in slums. For instance, a garment worker who cannot afford a flat may share one small room in a slum, which often lacks clean water and proper sanitation. Another problem is that villages lose their young and energetic workers, which leaves older people behind. Farms may then have too few workers, and elderly parents may have nobody nearby to care for them. As a result, this movement puts pressure on both cities and villages.

**Conclusion** (31 words)
> In conclusion, rural workers move because agriculture pays little and urban areas provide more opportunities. However, this movement puts heavy pressure on city housing and deprives villages of their younger workers.

**Total: 286 words** ✅

**Notice:** the garment factory in BP1 returns as the garment worker in BP2, which connects the reasons to the problems.

**Rules for choosing ideas**
1. **Find the category first** (e.g. *workers moving to cities* → Work → Migration for Work and Brain Drain).
2. **Look for both answers in the same passage.** Most passages give reasons first and then effects or solutions.
3. **Simple beats clever.** Pick the idea you can explain and give an example for.
4. **Leave out balanced endings** when you need one clear side. Idea Bank passages often end with *both sides have a role*.

## 14. Useful Language Bank (simple and safe)

| Purpose | Phrases |
|---|---|
| Paraphrase "increasing" | *is rising*, *a growing number of*, *is becoming more common* |
| Paraphrase "decreasing" | *fewer*, *is becoming less common*, *a declining number of* |
| Give a reason | *This is mainly because …*, *One of the main reasons for this is …* |
| Give a problem | *The most serious problem caused by this trend is …*, *Another problem is …* |
| Give a solution | *The most effective solution is for … to …*, *In addition, … could …* |
| Give a factor, skill or way | *One important factor is …*, *Another important way is …* |
| Give your opinion | *I firmly believe that …*, *As for whether …, I firmly believe that …* |
| Say no clearly | *is not the best way*, *is not the main cause*, *is not an effective measure* |
| Say good or bad | *a positive / negative development*, *beneficial*, *harmful*, *damaging* |
| Answer the other side | *Although some people argue that …, …* |
| Explain | *When …, …*, *If …, …*, *This means that …* |
| Close | *Consequently, …*, *Therefore, …*, *Together, these measures would …*, *In conclusion, …* |

## 15. 40-Minute Exam Plan

| Time | Task |
|---|---|
| **0–2 min** | Write Q1 and Q2 separately. Mark each one **List** or **Opinion**. Underline the exact topic and the word *other*. |
| **2–5 min** | Plan both answers: two ideas for List, one side and one reason for Opinion. Add one example for each paragraph. |
| **5–9 min** | Introduction (Paraphrase → Answer 1 + answer 2) |
| **9–19 min** | Body Paragraph 1 — the answer to Q1 |
| **19–29 min** | Body Paragraph 2 — the answer to Q2 |
| **29–34 min** | Conclusion (Answer 1 in new words → Answer 2 in new words) |
| **34–40 min** | Check: spelling, articles (a/the), plurals (-s), subject–verb agreement, word count |

## 16. Final Checklist

- [ ] I wrote out **Q1 and Q2 separately** and marked each one List or Opinion.
- [ ] BP1 answers **Q1**, BP2 answers **Q2**, and both have similar space.
- [ ] I followed the first word of the question and was not tricked by *do you think*.
- [ ] If the question says *other*, my ideas are **different** from the one in the question.
- [ ] Each Opinion block has **one clear side**, with no *partly* or *it depends*.
- [ ] My opinion is the **same** in the introduction, the body and the conclusion.
- [ ] I wrote no *I* in a List + List essay, and no *This essay will …* in any essay.
- [ ] My introduction gives my **real answers** to both questions.
- [ ] Each solution has **WHO + WHAT + HOW**.
- [ ] Each example **shows the Explain sentence right before it**, and it is realistic with no fake facts.
- [ ] My R sentence has **my side after the comma** and no *but*.
- [ ] My Link sentences add no new idea.
- [ ] My conclusion answers **both** questions in new words and adds no new idea.
- [ ] My ideas and collocations come from the matching **idea bank chapter**.
- [ ] Introduction 30–40, each body paragraph 90–120 (aim for about 105), conclusion 30–40, **total 260–300**.

## 17. Common Mistakes to Avoid

| Mistake | Fix |
|---|---|
| Answering Q1 well and Q2 in two lines | Aim for about 105 words in each body paragraph |
| Mixing both answers in one paragraph | One question, one paragraph |
| Treating *Why do you think …?* as an opinion question | Use the 5-second test (Section 2) |
| Giving reasons but no side for *Is this good or bad?* | The Opinion block opens with *I firmly believe that …* |
| Suggesting the same idea when the question says *other* | Choose something different (Section 2) |
| Answering *yes* to *Is this the best way?*, then listing other solutions | Answer *no*, so Q2 follows naturally (Section 4) |
| *It helps, but it is not the best solution alone.* | One clear side: *this is not the best way because …* |
| Writing about the general topic | Answer the exact words: *sales staff*, *government spending* |
| Writing *This essay will …* | Name your real answers in the introduction |
| Using *I think* in a List block | Write *One of the main reasons is …* |
| Adding an R sentence to a List block | R belongs in the Opinion block only |
| Using the *Although* introduction or *While* conclusion from other guides | Use this guide's *[Answer 1], and [answer 2]* formula |
| Listing three or four ideas with no development | Two ideas in a List block, one with an example |
| An example about the topic but not about the Explain sentence | Use the 5-second test (Section 8) |
| Inventing statistics or studies | Use a realistic person or situation |
| A conclusion that answers only one question | One sentence for each answer |
| Under 260 words | Follow the plan: 35 + 105 + 105 + 35 |
| Over 300 words in practice | Cut extra details, but keep the explanation and the example |
