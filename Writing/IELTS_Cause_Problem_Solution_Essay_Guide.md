# IELTS Writing Task 2 — Cause/Problem + Solution Essay Guide

> **Goal:** Band 7+ with one fixed structure you can remember under exam pressure.
> **Length:** minimum **260 words**, maximum **300 words**, target **about 280 words**.
> **Rule:** same 4 paragraphs every time. **BP1 explains the causes or problems. BP2 gives the solutions. Only BP1 changes between the two essay types.**
> **Ideas:** simple ideas from your topic-wise idea bank, developed well. **No opinion unless the question asks for one.**

---

## 1. The Memory Card (learn this first)

```text
ASK     What does the FIRST question want?
        Why does it happen?       -> CAUSE essay
        What harm does it do?     -> PROBLEM essay

LENGTH  260-300 words. Plan: 35 + 105 + 105 + 35 = 280.

INTRO   (30-40)    Paraphrase the situation.
                   CAUSE:   This is mainly because C1 and C2, but S1 and S2 can tackle this problem.
                   PROBLEM: This can lead to P1 and P2, but S1 and S2 can reduce these effects.

BP1     (90-120)   P  One of the main causes of this trend is that ...
                      (or) The most serious problem caused by this trend is ...
                   E  When ..., ... / ..., so ...
                   X  For example, a ... who ..., and this ...
                   P  Another important cause/problem is ...
                   E  ...; as a result, ...
                   L  Consequently, ...

BP2     (90-120)   S  The most effective solution is for WHO to DO WHAT. (fixes C1 or P1)
                   E  When/If ..., ... (HOW it works)
                   X  For instance, a ... who ..., which ...
                   S  In addition, WHO could DO WHAT. (fixes C2 or P2)
                   E  When ..., ..., so ...
                   L  Together, these measures would ...

CONCL   (30-40)    In conclusion, [C1 + C2 or P1 + P2 in new words].
                   [S1 + S2 in new words] would [final result].
```

**One paragraph shape to learn:** BP1 and BP2 both use **Point, Explain, Example, Point, Explain, Link**.

**The golden rule:** solution 1 fixes cause or problem 1, and solution 2 fixes cause or problem 2.

## 2. Cause or Problem? (Clear this confusion first)

### The timeline

A cause comes **before** the situation. A problem comes **after** it.

```text
   CAUSE       ->       SITUATION       ->       PROBLEM
why it happens     (the question's topic)     the harm it does

 "because ..."                              "as a result ..."
```

**The 5-second test.** Put your idea into one of these sentences:

| Test sentence | If it makes sense, your idea is a |
|---|---|
| *This situation happens **because** ___.* | **Cause** |
| ***Because of** this situation, ___.* | **Problem** |

### One topic, two different essays

**Situation: fewer people are walking.**

| | Cause essay | Problem essay |
|---|---|---|
| **The question asks** | *What are the reasons for this?* | *What problems does this cause?* |
| **BP1 idea 1** | City streets are unsafe | People gain weight and become less healthy |
| **BP1 idea 2** | Technology removes the need to walk | More cars mean more traffic and pollution |
| **What BP2 does** | Removes the reason | Reduces the harm |
| **BP2 solution 1** | Build safe footpaths | Bring daily exercise into schools and workplaces |
| **BP2 solution 2** | Build walking into daily routines | Improve public transport |

> ⚠️ **The most common mistake:** writing *"Fewer people walk, so obesity is rising"* in a **Cause** essay. Obesity is a result, not a reason. You have answered a question that was not asked, and the first part of the real question stays unanswered.

### ⭐ The "problem" word trap

The word *problem* does **not** make it a Problem essay. Many questions use *this problem* simply to mean the topic. **Look only at what the first question asks you to find.**

| Question | The trap | Essay type |
|---|---|---|
| **WRK-06:** *What are the reasons for this? How can this problem be overcome?* | *problem* appears, but the first question asks for reasons | **Cause** |
| **HEA-09:** *What are the reasons for this? What can be done to tackle this problem?* | Same trap | **Cause** |
| **FOO-08:** *…which could result in many problems when they grow older… Why do you think so many children are overweight? What could be done to solve this problem?* | The background mentions problems, but the question asks *why* | **Cause** |
| **TOU-02:** *What problems does this cause for the environment? What measures could be taken to solve the problems?* | None. It asks for the harm directly | **Problem** |
| **WRK-02:** *What will be the consequences of this? What solutions can you offer?* | *Consequences* is a different word for the results | **Problem** |

### What the question words mean

| The first question says | You write | The second question says | You write |
|---|---|---|---|
| *What are the causes / reasons?* · *Why is this?* · *Why do you think this is?* | **Causes** | *What can be done?* · *How can this be solved / tackled / overcome?* · *What measures can be taken?* · *What solutions can you suggest?* | **Solutions** |
| *What problems does this cause?* · *What are the effects / consequences?* | **Problems** | | |

> **Answer the exact question.** TOU-02 asks about problems *for the environment*, so problems for airlines do not count. TEC-08 asks what problems *parents* face, so general dangers for children are not enough. BUS-06 asks how to encourage people to *buy local products*, so your solutions must do that.

### Do not mix up your four guides

| | Adv / Disadv | Agree / Disagree | Discuss Both Views | **This guide** |
|---|---|---|---|---|
| **Opinion** | Only if asked | Yes | Yes | **Only if asked** |
| **Intro, sentence 2** | *Although …* | *I completely agree …* | *I completely support the latter …* | ***This is mainly because …, but …*** |
| **BP1** | 2 advantages | Idea 1 | The other view | **2 causes or 2 problems** |
| **BP2** | 2 disadvantages | Idea 2 | My view | **2 solutions** |
| **Body shape** | 7 sentences | P E E X L · P E X R L | P E E X L · P E X R L | **P E X P E L, both paragraphs** |
| **R sentence** | No | BP2 | BP2 | **No, there is no other side to answer** |
| **Conclusion** | *While …* | *I firmly believe …* | *While … I firmly believe …* | ***In conclusion, [causes/problems]. [Solutions] would …*** |

## 4. Task Response — What the Examiner Wants

| # | Job | Where you do it | If you miss it |
|---|---|---|---|
| 1 | Answer the **first** question | BP1 | Part of the question is not answered |
| 2 | Answer the **second** question | BP2 | Part of the question is not answered |
| 3 | **Develop** both parts with an explanation and an example | BP1 and BP2 | Your ideas stay as a list |
| 4 | Stay on the **exact** topic | Every sentence | Your ideas lose focus |

**Give both parts similar space.** A long BP1 with two lines of solutions leaves the second question underdeveloped.

### No opinion is needed

The question asks you to explain and suggest, not to choose a side. Your clear answer **is** your position, so you can write the whole essay without *I*.

| ❌ Avoid | ✅ Write instead |
|---|---|
| *In my opinion, the main cause is …* | *One of the main causes of this trend is …* |
| *I think governments should …* | *Governments should …* |
| *This essay will discuss the causes and solutions.* | Name the actual causes and solutions (Section 7) |

> **Check the wording.** *"Why do you **think** this is?"* only asks for reasons, so you still need no opinion. *"Do you think this is a **good thing**?"* does ask for your opinion, so it is not this essay type.

## 5. The Fixed Structure

| Paragraph | Content | Sentences | Words |
|---|---|---|---|
| **Introduction** | a. Paraphrase the situation<br>b. 2 causes or problems + 2 solutions | 2 | **30–40** |
| **Body Paragraph 1** | 2 causes or 2 problems — **P E X P E L** | 6 | **90–120** |
| **Body Paragraph 2** | 2 solutions — **P E X P E L** | 6 | **90–120** |
| **Conclusion** | a. Causes or problems in new words<br>b. Solutions in new words + final result | 2 | **30–40** |
| **Total** | | 16 | **260–300** (target about 280) |

### ⭐ The word plan: 35 + 105 + 105 + 35 = 280

Your paragraph limits do not automatically give the right total:

| If you write | Total | Result |
|---|---|---|
| The minimum in every paragraph (30 + 90 + 90 + 30) | 240 | ❌ Too short |
| **The plan (35 + 105 + 105 + 35)** | **280** | ✅ Safe |
| The maximum in every paragraph (40 + 120 + 120 + 40) | 320 | ❌ Too long |

- **Each body paragraph needs about 105 words.** Six sentences × about 18 words = 108.
- **Do not count every word in the exam.** In practice, find out how many lines 280 words fills in your handwriting. Then you can check the length at a glance.

> **This is your practice rule, not an IELTS rule.** IELTS has a 250-word minimum and no maximum, and extra length does not earn marks by itself. If you reach 305 words in the exam, do not cross out a good sentence in a hurry. Use that time to check your grammar.

### Why two points in each body paragraph?

Questions usually say *causes*, *problems* and *solutions* (plural), so two of each answers the question fully. Each paragraph still has one central topic: *why this happens*, *what harm it does* or *how to solve it*. Like an Advantages/Disadvantages paragraph, it is an exception to the "one main idea" rule in your [Body Paragraph Rules](IELTS_Body_Paragraph_Rules.md).

Your first point gets the full development with an example. Your second point is shorter, with no example. That is how two points fit into about 105 words.

> **If the question says *the reason* (singular), two reasons are still fine.**
> **Emergency exit:** if you can only think of one good idea, develop it with P E E X L. One well-developed idea is better than two weak ones.

### ⭐ The Mirror Rule: each solution fixes one cause or problem

This is the most useful planning rule in this essay. You think of 2 causes or problems, then ask of each one: *"What would fix this?"* Half of your thinking is finished, and the two paragraphs connect naturally.

| Essay type | Point 1 | → Solution 1 | Point 2 | → Solution 2 |
|---|---|---|---|---|
| **Cause** (HEA-09) | Streets are unsafe | Build safe footpaths | Technology removes effort | Build walking into daily routines |
| **Problem** (TOU-02) | High carbon emissions | Fair environmental taxes | Noise and land loss near airports | High-speed trains replace short flights |

**In a Cause essay, the solution removes the reason. In a Problem essay, the solution reduces the harm.**

> This is your planning rule, not an IELTS rule. If one solution naturally fixes both points, use it and add a second solution that also helps. Never write something unnatural just to make the two paragraphs match.

### ⭐ The same ideas run through the whole essay

The same ideas appear in all four paragraphs, in the same order. Only the words change.

| | Cause 1 | Cause 2 | Solution 1 | Solution 2 |
|---|---|---|---|---|
| **Introduction** | *city streets are unsafe* | *technology has made it unnecessary* | *safer footpaths* | *better daily habits* |
| **Body paragraphs** | *unpleasant and dangerous* | *removed much of the physical effort* | *make streets safer for pedestrians* | *bring walking back into everyday routines* |
| **Conclusion** | *urban streets are hazardous* | *technology has reduced physical effort* | *safer pedestrian routes* | *small changes to everyday habits* |

## 6. Finding Ideas in 3 Minutes

**First look in your idea bank (Section 15).** If you cannot remember anything, use these two tables.

### Finding causes or problems

| Area | Possible cause | Possible problem |
|---|---|---|
| **Money** | low income, high costs | debt, poverty, higher public spending |
| **Technology** | machines, phones, online services | distraction, job losses, less contact |
| **Work and time** | long hours, busy lives | stress, less family time |
| **Education and awareness** | lack of knowledge, poor training | poor decisions, fewer opportunities |
| **Government** | weak laws, poor planning, low funding | unsafe conditions, inequality |
| **Family and society** | changing habits, weaker family support | loneliness, weaker communities |
| **Health** | poor diet, little exercise | illness, pressure on hospitals |
| **Environment** | traffic, waste, fuel use | pollution, loss of nature |

### Finding solutions: ask WHO can act

| WHO | WHAT they can do |
|---|---|
| **Governments** | pass laws, set fines or taxes, fund services, build infrastructure |
| **Schools and universities** | teach skills, provide programmes, advise students and parents |
| **Employers** | offer flexible hours, training, better pay or facilities |
| **Parents and families** | set limits, set a good example, talk to children |
| **Individuals** | change daily habits and make responsible choices |
| **Media and companies** | run clear campaigns, change products or advertising |

**Simple beats clever.** Choose the ideas that you can **explain with an example**, not the ones that sound most impressive.

## 7. Introduction Template

**Two sentences, 30–40 words.**

**a. Paraphrase the situation (~12–16 words)**

> *Despite …, …* · *As …, …* · *These days, …* · *Nowadays, …*

Change the words **and** the sentence order. Do not copy the question.

**b. The whole answer in one sentence (~20–25 words)**

| Essay type | Formula |
|---|---|
| **Cause** | *This is mainly because [cause 1] and [cause 2], but [solution 1] and [solution 2] can tackle this problem.* |
| **Problem** | *This [trend/growth] can lead to [problem 1] and [problem 2], but [solution 1] and [solution 2] can reduce these effects.* |

Write both causes or problems in the same grammar shape, and both solutions in the same grammar shape. Keep each idea to about 3–6 words, because the details belong in the body paragraphs.

| ❌ Avoid | Why | ✅ Better |
|---|---|---|
| *This essay will examine the causes and suggest some solutions.* | A memorised sentence with no idea in it, as in your other guides | Name the real causes and solutions |
| *This is because of many reasons, and there are many solutions.* | Says nothing | *This is mainly because city streets are unsafe and …* |
| *In my opinion, this is a serious problem.* | The question did not ask | Leave it out |
| *Although streets are unsafe, but …* | Never use *but* after *Although* | *…, but …* is correct **only** in the formula above, with no *Although* |

## 8. Body Paragraph 1 — Causes or Problems

> **General rules for every essay type:** see [IELTS_Body_Paragraph_Rules.md](IELTS_Body_Paragraph_Rules.md). If a sentence opener sounds unnatural in your essay, change it.

| # | Role | Cause essay starter | Problem essay starter | The question it answers |
|---|---|---|---|---|
| 1 | **P** Point 1 | *One of the main causes of this trend is that …* | *The most serious problem caused by this trend is …* | What is the first idea? |
| 2 | **E** Explain | *When …, …* · *…, so …* | *…, and …* · *This is because …* | **Cause:** How does it lead to the situation? **Problem:** How does it cause harm? |
| 3 | **X** Example | *For example, a … who …, and this …* | Same | Shows sentence 2 happening |
| 4 | **P** Point 2 | *Another important cause is …, which …* | *Another problem is …* | What is the second idea? |
| 5 | **E** Explain | *…; as a result, …* | *…, which …* | Same question as sentence 2 |
| 6 | **L** Link | *Consequently, …* | *Consequently, …* | What is the overall result? |

Sentence 1 is both your **topic sentence** and your first point, so you do not need a separate topic sentence.

**Check your direction in BP1:**
- **Cause essay:** your Explain sentences move **towards** the situation (*unsafe streets → stress → people avoid walking*).
- **Problem essay:** your Explain sentences move **away from** the situation (*more flights → more fuel burned → more climate change*).

**No solutions in BP1.** Keep them for BP2, or you will have nothing left to develop.

## 9. Body Paragraph 2 — Solutions

| # | Role | Safe starter | The question it answers |
|---|---|---|---|
| 1 | **S** Solution 1 | *The most effective solution is for [who] to [do what].* | WHO acts, and WHAT do they do? |
| 2 | **E** Explain | *When / If …, …* | HOW does it fix the cause or problem? |
| 3 | **X** Example | *For instance, a … who …, which …* | What would this look like in real life? |
| 4 | **S** Solution 2 | *In addition, [who] could [do what].* | WHO acts, and WHAT do they do? |
| 5 | **E** Explain | *When …, …, so …* | HOW does it fix the cause or problem? |
| 6 | **L** Link | *Together, these measures would …* | What is the final result? |

### ⭐ The Solution formula: WHO + WHAT + HOW

A solution has **not** been developed until it answers all three.

| | ❌ Vague | ✅ Developed |
|---|---|---|
| **WHO** | *People should do something.* | *Governments …* |
| **WHAT** | *…should take the necessary steps.* | *…should make streets safer for pedestrians.* |
| **HOW** | *…and then the problem will be solved.* | *When city planners build safe footpaths and separate them from traffic, walking becomes pleasant and practical rather than stressful.* |

**Phrases that need more detail**

| ❌ Empty on its own | ✅ Add the detail |
|---|---|
| *Governments should take strict action.* | Which law or fine? Who must follow it? |
| *Awareness should be raised.* | Who runs the campaign, and what will people do differently afterwards? |
| *People should change their mindset.* | Which daily habit will change? |
| *This problem can be solved easily.* | Do not promise too much. Use *can help to reduce* |

**Use careful language.** Solutions have not happened yet, so use *should, could, can, would*, and do not claim that they will solve everything.

## 10. How to Develop a Body Paragraph, Step by Step

**Question (HEA-09):** *Walking is known to be beneficial for health and yet fewer and fewer people are walking these days. What are the reasons for this? What can be done to tackle this problem?*

**The plan, using only a few words:** Cause 1: unsafe streets → parent takes a rickshaw. Cause 2: technology.

| Step | Ask yourself | You write |
|---|---|---|
| **1. Point** | What is my first cause? | *One of the main causes of this trend is that walking in large cities has become unpleasant and dangerous.* |
| **2. Explain** | How does this make people walk less? | *Heavy traffic, air pollution and broken footpaths make short journeys on foot stressful, so many people avoid them.* |
| **3. Example** | Who does this happen to in real life? | *For example, a parent who must walk beside fast buses on a broken footpath may take a rickshaw for a five-minute journey, and this soon becomes a habit.* |
| **4. Point** | What is my second cause? | *Another important cause is technology, which has removed much of the physical effort from daily life.* |
| **5. Explain** | How does this make people walk less? | *Lifts replace stairs, and online shopping means that people do not even need to walk to the shops.* |
| **6. Link** | What is the overall result? | *Consequently, walking has gradually disappeared from the daily routines of many people.* |

**Every sentence continues the one before it:** *unsafe* → *stressful, so people avoid walking* → *a parent on a broken footpath takes a rickshaw*.

### The Example rule — one chain from Point to Example

The example must show the Explain sentence right before it. **Point 1 → Explain → Example is one chain.**

| ❌ Same topic, different idea | ✅ Shows the explanation |
|---|---|
| **E:** *Heavy traffic and broken footpaths make short journeys stressful.* **X:** *a person who watches television every evening may become overweight.* (E is about unsafe streets, but X is about screens and weight.) | **E:** the same sentence. **X:** *a parent who must walk beside fast buses on a broken footpath may take a rickshaw for a five-minute journey.* |

**The 5-second test:** read E and X together. If the same situation is not in both, change the example. In your plan, write the example first, then the Explain sentence that leads to it.

**Examples must be realistic, not fake facts.** *A parent who takes a rickshaw* is safe. Never invent a statistic, a study or an expert. For a solution, describe what **would** happen: *a parent who can reach the market on a safe footpath may no longer need a rickshaw.*

### Fixing the length

| Problem | Fix |
|---|---|
| **Under 90 words** | Ask *"why?"* or *"what happens next?"* about your second point, and add that detail |
| **Over 120 words** | Shorten the example. It should be one sentence, not a story |
| **Essay under 260 words** | Aim for about 105 in each body paragraph, not 90 |
| **Essay over 300 words** | Cut extra details and repeated ideas. **Never cut the explanation or the example** |

## 11. Sentence Variety and Linking Devices

### Sentence variety — the key to band 7 in Grammar

Most sentences should be about 15–25 words, and your example can reach about 30. You do not need every type in every paragraph.

| Type | Pattern | Example |
|---|---|---|
| **Long simple** | *[long subject] + verb + object* | *Together, these measures would make walking a normal part of modern life again.* |
| **Compound** | *…, so … · …, and …* | *Heavy traffic, air pollution and broken footpaths make short journeys on foot stressful, **so** many people avoid them.* |
| **Complex** | *that / when / which / who* | ***When** passengers have a fast and comfortable alternative, short flights become less necessary …* |
| **Compound-complex** | *a … who …, and this …* | *For example, a parent **who** must walk …, **and** this soon becomes a habit.* |
| **Passive** | *be + past participle* | *… the money raised **could be invested** in clean energy.* |
| **Verb+ing as subject** | *Building …, Introducing …* + verb | ***Building** safe footpaths **is** one of the simplest ways to encourage walking.* |

**Rules**
- **The example is never a short simple sentence.** Add *who / which / while / when*.
- Do not start two sentences in a row with the same word.
- **Accuracy comes first.** A correct compound sentence scores higher than a broken complex sentence. Use the structures you have practised.

### Linking devices — Coherence & Cohesion

| Job | Device | Where it goes |
|---|---|---|
| Show cause | *This is mainly because …* · *…, so …* · *When …, …* | Intro, E |
| Show result | *…; as a result, …* · *…, which …* · *Consequently, …* | E, X, L |
| Add a second point | *Another important cause / problem is …* · *In addition, …* | Point 2 |
| Give an example | *For example, …* · *For instance, …* | X |
| Move to solutions | *but … can tackle this problem* | Intro |
| Close the solutions | *Together, these measures would …* | BP2 L |
| Close the essay | *In conclusion, …* | Conclusion |

**Reference words also link your paragraphs.** Starting BP2 with *these emissions* or *this problem* connects it directly to BP1.

> ⚠️ **Use one linker in a sentence.** Never stack them (*~~Moreover, in addition,~~*), and do not start every sentence with one.

## 12. Conclusion Template

**Two sentences, 30–40 words.** New words, same ideas, no new idea.

**a. Causes or problems in new words (~15 words)**

| Essay type | Formula |
|---|---|
| **Cause** | *In conclusion, [the situation in new words] because [cause 1] and [cause 2].* |
| **Problem** | *In conclusion, [the situation in new words] harms / damages [problem 1] and [problem 2].* |

**b. Solutions in new words + final result (~15 words)**

> *[Solution 1] and [solution 2] would [final result].*

| ❌ Avoid | Why |
|---|---|
| *In conclusion, this is a serious problem that must be solved.* | Fits every question and answers nothing |
| *Schools should also teach children about nutrition.* | A new idea has no support, so leave it out |
| *I firmly believe that the government should act.* | An opinion was not asked for |
| Repeating your introduction word for word | Say the same meaning in new words |

## 13. Model Essays

### Model Essay A — Cause + Solution

**Question (HEA-09):** *Walking is known to be beneficial for health and yet fewer and fewer people are walking these days. What are the reasons for this? What can be done to tackle this problem?*

**5-minute plan**
- **Type:** the first question asks for *reasons*, so this is a **Cause** essay. (*Problem* in the second question is the trap.)
- **Cause 1:** unsafe streets → parent takes a rickshaw. **Solution 1:** governments build safe footpaths → the same parent walks.
- **Cause 2:** technology removes effort. **Solution 2:** workplaces and individuals bring walking back.
- **Idea bank:** Chapter 04 Health → *Exercise, Walking and the Sedentary Lifestyle*.

**Introduction** (38 words)
> Despite its well-known health benefits, walking is becoming less common in modern life. This is mainly because city streets are unsafe and technology has made it unnecessary, but safer footpaths and better daily habits can tackle this problem.

**Body Paragraph 1 — causes** (111 words)
> One of the main causes of this trend is that walking in large cities has become unpleasant and dangerous. Heavy traffic, air pollution and broken footpaths make short journeys on foot stressful, so many people avoid them. For example, a parent who must walk beside fast buses on a broken footpath may take a rickshaw for a five-minute journey, and this soon becomes a habit. Another important cause is technology, which has removed much of the physical effort from daily life. Lifts replace stairs, and online shopping means that people do not even need to walk to the shops. Consequently, walking has gradually disappeared from the daily routines of many people.

**Body Paragraph 2 — solutions** (113 words)
> The most effective solution is for governments to make streets safer for pedestrians. When city planners build **safe footpaths** and separate them from traffic, walking becomes pleasant and practical rather than stressful. For instance, a parent who can reach the local market on a wide, well-lit footpath may no longer need a rickshaw, which adds exercise to their day at no cost. In addition, employers and individuals can bring walking back into everyday routines. Workplaces can encourage staff to use the stairs, while people can walk to nearby shops instead of ordering online, and these small changes quickly add up. Together, these measures would make walking a normal part of modern life again.

**Conclusion** (32 words)
> In conclusion, people walk less because urban streets are hazardous and technology has reduced physical effort. Safer pedestrian routes and small changes to everyday habits would encourage more people to walk regularly.

**Total: 294 words** ✅

### Sentence map of Essay A

| Part | Role | Linker | Sentence structure |
|---|---|---|---|
| Intro a | Paraphrase | *Despite* | Long simple |
| Intro b | 2 causes + 2 solutions | *This is mainly because* · *but* | Compound-complex |
| BP1 1 | **P** Cause 1 | *One of the main causes* | Complex (*that*) |
| BP1 2 | **E** | *so* | Compound |
| BP1 3 | **X** | *For example* · *this* | Compound-complex (*who* + *and*) |
| BP1 4 | **P** Cause 2 | *Another important cause* | Complex (*which*) |
| BP1 5 | **E** | *and* | Compound-complex (*and* + *that*) |
| BP1 6 | **L** | *Consequently* | Long simple |
| BP2 1 | **S** Solution 1 | *The most effective solution* | Long simple |
| BP2 2 | **E** | *When* | Complex |
| BP2 3 | **X** | *For instance* · *which* | Complex (*who* + *which*) |
| BP2 4 | **S** Solution 2 | *In addition* | Simple |
| BP2 5 | **E** | *while* · *and* | Compound-complex |
| BP2 6 | **L** | *Together* · *these measures* | Long simple |
| Concl a | Causes in new words | *In conclusion* · *because* | Complex |
| Concl b | Solutions in new words + result | | Long simple |

**Notice:** the parent in BP1 returns in BP2. The same person shows both the cause and the solution, so the two paragraphs connect naturally.

### Model Essay B — Problem + Solution

**Question (TOU-02):** *As a result of tourism and the increasing number of people travelling, there is a growing demand for more flights. What problems does this cause for the environment? What measures could be taken to solve the problems?*

**5-minute plan**
- **Type:** the first question asks for *problems*, so this is a **Problem** essay, and they must be problems for the **environment**.
- **Problem 1:** carbon emissions → a tourist's return flight. **Solution 1:** fair taxes → a business traveller replaces trips with online calls.
- **Problem 2:** noise and land loss near airports. **Solution 2:** high-speed trains replace short flights.
- **Idea bank:** Chapter 03 Environment → *Air Travel, Tourism and the Environment*.

**Introduction** (35 words)
> As tourism expands, the demand for air travel continues to rise around the world. This growth increases carbon emissions and damages areas near airports, but fair environmental taxes and high-speed trains can reduce these effects.

**Body Paragraph 1 — problems** (107 words)
> The most serious environmental problem caused by this growth is the high level of **carbon emissions**. Aeroplanes burn large amounts of fuel, and there are few clean alternatives for long-distance flights at present. For example, a tourist who takes one long-distance return flight can produce as much carbon as several months of driving, and this damage grows as more people travel. Another problem is the harm that airports cause to the areas around them. They create noise pollution for nearby residents and take up large areas of land, which may once have been farmland or forest. Consequently, more flights damage both the global climate and local communities.

**Body Paragraph 2 — solutions** (113 words)
> The most effective way to reduce these emissions is to introduce fair **environmental taxes**, especially for people who fly very frequently. Higher prices could reduce unnecessary flights, and the money raised could be invested in clean energy. For instance, a business traveller who pays more for every extra trip may replace some meetings with online calls, which reduces emissions without affecting families who rarely fly. In addition, governments could invest in high-speed trains for shorter journeys. When passengers have a fast and comfortable alternative, short flights become less necessary, so airports cause less noise and need less new land. Together, these measures would allow people to travel while causing far less environmental damage.

**Conclusion** (30 words)
> In conclusion, rising demand for flights harms the climate and the communities living near airports. Well-designed taxes and better rail connections would limit this damage without preventing people from travelling.

**Total: 285 words** ✅

**Notice:**
- **BP2 opens with *these emissions*,** which connects it directly to BP1.
- **Solution 2 explains the mirror:** fewer short flights mean *less noise and less new land*, which answers Problem 2.
- **Essays A and B share the same six-sentence shape.** Only the content of BP1 changes.

## 14. Same Plan, Other Question Shapes

These questions are close relatives. You keep the same introduction, conclusion and sentence skills, and only the content of the body paragraphs changes.

| The question asks for | Intro sentence b | BP1 | BP2 | From your sheets |
|---|---|---|---|---|
| **Causes + Problems** | *This is mainly because C1 and C2, and it can lead to P1 and P2.* | 2 causes — P E X P E L | 2 problems — P E X P E L | WRK-10, WRK-14, FAM-07 |
| **Solutions only** | *[Who] can tackle this by [S1], and [who] can help by [S2].* | Solution 1 — P E E X L | Solution 2 — P E E X L | EDU-15, CRI-15, TOU-06, ENV-16 |
| **Solutions by two groups** | *Governments can [S1], while individuals can [S2].* | The first group — P E E X L | The second group — P E E X L | ENV-12 |

**When a paragraph has only one idea,** use P E E X L, because that one idea now has about 105 words to itself. In a Solutions-only essay, each solution still needs WHO + WHAT + HOW.

**Rules for choosing ideas**

4. **Change the words to fit the question.** Use exact sentences when they fit, but never copy a whole paragraph.

## 18. Final Checklist

- [ ] I read the **first** question and did not let the word *problem* trick me.
- [ ] My ideas pass the test: *Cause = "This happens because ___."* · *Problem = "Because of this, ___."*
- [ ] I answered the **exact** question, not only the general topic.
- [ ] I wrote **no opinion** and no *I think*, because the question did not ask for one.
- [ ] I wrote no *This essay will …* sentence.
- [ ] My introduction names my **real** causes or problems and my **real** solutions.
- [ ] BP1 has **no solutions**, and BP2 has **no new causes or problems**.
- [ ] Each solution **fixes** a cause or problem from BP1, wherever this is natural.
- [ ] Each solution has **WHO + WHAT + HOW**.
- [ ] Each example **shows the Explain sentence right before it**, and it is realistic with no fake facts.
- [ ] My examples are **long complex sentences**, not short simple ones.
- [ ] My Link sentences add no new idea.
- [ ] I used *should, could, can, would, may* for careful language.
- [ ] My conclusion uses **new words** and adds **no new idea**.
- [ ] My ideas and collocations come from the matching **idea bank chapter**.
- [ ] Introduction 30–40, each body paragraph 90–120 (aim for about 105), conclusion 30–40, **total 260–300**.
- [ ] Spelling of key words checked: *conclusion, paraphrase, sentence, explanation, government, environment, consequence, measure, tackle, necessary*.

## 19. Common Mistakes to Avoid

| Mistake | Fix |
|---|---|
| Writing effects in a Cause essay (*fewer people walk, so obesity rises*) | Use the test: *This happens **because** ___* (Section 2) |
| Writing causes in a Problem essay | Use the test: ***Because of** this, ___* (Section 2) |
| Treating the question as a Problem essay because it says *this problem* | Look only at what the **first** question asks (Section 2) |
| Writing about the general topic | Answer the exact question: *for the environment*, *parents face*, *buy local products* |
| Adding *In my opinion* or *I think* | Leave them out unless the question asks |
| Writing *This essay will discuss …* | Name your real ideas in the introduction |
| Using the *Although* introduction or *While* conclusion from your other guides | Use this guide's formulas (Section 3) |
| Adding an R sentence (*Although some people argue …*) | This essay has no other side to answer |
| Putting solutions in BP1 | Keep them for BP2 |
| Listing three or four ideas with no development | Only 2, with one explained by an example |
| Solutions with no connection to BP1 | Use the Mirror Rule (Section 5) |
| Vague solutions (*Governments should take strict action.*) | Add WHO + WHAT + HOW (Section 9) |
| Writing a long BP1 and a very short BP2 | Aim for about 105 words in each |
| Promising too much (*This will completely solve the problem.*) | Use *can help to reduce*, *would*, *could* |
| An example about the topic but not about the Explain sentence | Use the 5-second test (Section 10) |
| Inventing statistics or studies | Use a realistic person or situation |
| A new idea in the conclusion | Only your existing causes or problems and solutions |
| Under 260 words because every paragraph is at its minimum | Follow the plan: 35 + 105 + 105 + 35 |
| Over 300 words in practice | Cut extra details, but keep the explanation and the example |
