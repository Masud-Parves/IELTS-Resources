## [Day 5] Double Consonants, Silent Letters and Vowel Confusion

### Learning objectives

By the end of today you will be able to:

- spell **57 of the most-misspelt words in English**, many of which are IELTS Section 1 favourites (*accommodation, address, questionnaire, receipt, Wednesday*);
- use the **doubling rule** to decide between one and two consonants;
- remember where the **silent letters** are;
- choose between **ie/ei, ea/ee, ai/ay** and **ou/ow**;
- write **difficult consonant groups** (*ph, gh, ch, tch, dge, qu, sc*) and use **British spelling** consistently.

### Part A: Double consonants

> ⚠️ **A double consonant sounds exactly like a single one.** *Comittee* and *committee* sound the same, so you have to remember the letters.

#### The doubling rule (adding -ed, -ing, -er, -ence)

**Double the last consonant** when **all three** of these are true:

1. the word ends in **one vowel + one consonant** (*begin, occur, plan, stop*);
2. the **last syllable is stressed** (be**GIN**, oc**CUR**; all one-syllable words count);
3. the suffix **starts with a vowel** (*-ed, -ing, -er, -ence, -able*).

| Double ✅ | Don't double ❌ (stress is not on the last syllable) |
|---|---|
| be**gin** → begi**nn**ing | **vi**sit → visi**t**ed |
| oc**cur** → occu**rr**ed, occu**rr**ence | **o**pen → ope**n**ing |
| re**fer** → refe**rr**ed | **lis**ten → liste**n**ing |
| pre**fer** → prefe**rr**ed | **of**fer → offe**r**ed |
| ad**mit** → admi**tt**ed | de**vel**op → develo**p**ed, develo**p**ment |
| plan → pla**nn**ing · stop → sto**pp**ed · swim → swi**mm**ing | **ben**efit → benefi**t**ed |

⚠️ **British exception: a final -l after one vowel always doubles**, wherever the stress is: travel → trave**ll**ed, trave**ll**er · cancel → cance**ll**ed, cance**ll**ation · label → labe**ll**ed · model → mode**ll**ing · level → leve**ll**ed · marvel → marve**ll**ous · counsel → counse**ll**or. (American English uses one *l*. Pick one style.)

#### Add, don't drop: prefixes and -ly / -ness

When you add a prefix or -ly / -ness, **keep every letter** of both parts:

| Part 1 | Part 2 | Word |
|---|---|---|
| dis | appear | di**s**appear (one s) |
| dis | satisfied | di**ss**atisfied (two s) |
| mis | spell | mi**ss**pell |
| un | necessary | u**nn**ecessary |
| im / ir / il | mature / regular / legal | i**mm**ature / i**rr**egular / i**ll**egal |
| final / real / usual | ly | fina**ll**y / rea**ll**y / usua**ll**y |
| careful / successful | ly | carefu**ll**y / successfu**ll**y |
| open / sudden | ness | ope**nn**ess / sudde**nn**ess |

### Part C: Vowel combinations

#### ie or ei?

**The rule:** *i before e, except after c, when the sound is /iː/.*

| ie (sound /iː/) | ei after c (sound /iː/) | ei (sound /eɪ/, as in *eight*) |
|---|---|---|
| bel**ie**ve, ach**ie**ve, f**ie**ld, p**ie**ce, ch**ie**f, br**ie**f, rel**ie**f, th**ie**f, n**ie**ce | re**cei**ve, **cei**ling, re**cei**pt, de**cei**ve, per**cei**ve, con**cei**ve | **ei**ght, w**ei**ght, n**ei**ghbour, fr**ei**ght, v**ei**n, r**ei**gn, b**ei**ge |

⚠️ **Exceptions to learn:** s**ei**ze, w**ei**rd, **ei**ther, n**ei**ther, l**ei**sure, prot**ei**n, caff**ei**ne, h**ei**ght, for**ei**gn, th**ei**r · and **cie** words with a /ʃ/ sound: an**cie**nt, effi**cie**nt, suffi**cie**nt, spe**cie**s, so**cie**ty, s**cie**nce.

#### ea or ee?

There is no reliable rule, so learn the **sound-alike pairs** and the **ea words that don't sound like /iː/**.

| ee | ea | Note |
|---|---|---|
| m**ee**t (*see someone*) | m**ea**t (*food*) | Same sound /iː/ |
| s**ee** | s**ea** | |
| w**ee**k (*7 days*) | w**ea**k (*not strong*) | |
| st**ee**l (*metal*) | st**ea**l (*take*) | |
| h**ee**l (*foot*) | h**ea**l (*get better*) | |
| b**ee**ch (*tree*) | b**ea**ch (*sand*) | |
| **-ee at the end** for people and agreements: employ**ee**, train**ee**, refug**ee**, attend**ee**, committ**ee**, guarant**ee**, degr**ee**, agr**ee** | **ea = /e/**: br**ea**d, h**ea**d, w**ea**ther, h**ea**lth ★, w**ea**lth, br**ea**kfast, h**ea**vy, r**ea**dy, pl**ea**sant, m**ea**sure, inst**ea**d, thr**ea**t, j**ea**lous · **ea = /eɪ/**: gr**ea**t, br**ea**k, st**ea**k | car**ee**r ★ (two e's) ≠ carr**ier** |

#### ai or ay?

| Rule | Examples |
|---|---|
| **ay** at the **end** of a word or syllable | d**ay**, w**ay**, p**ay**, st**ay**, holid**ay**, ess**ay**, del**ay**, displ**ay**, Mond**ay**, p**ay**ment, l**ay**er, m**ay**or |
| **ai** in the **middle**, before a consonant | tr**ai**n, r**ai**n, w**ai**t, p**ai**nt, m**ai**l, expl**ai**n, cont**ai**n, maint**ai**n, compl**ai**nt, det**ai**l |
| **ay** stays when you add an ending… | days, plays, stayed, delayed, displaying, payment |
| ⚠️ …**except** these three | p**ay** → p**ai**d · s**ay** → s**ai**d · l**ay** → l**ai**d |
| Unstressed **-ain** /ɪn/ or /ən/ | capt**ain** ★, mount**ain**, cert**ain**, barg**ain**, curt**ain**, fount**ain**, Brit**ain** |

#### ou or ow?

| Rule | Examples |
|---|---|
| **ow** at the **end** of a word, and before **n, l, el, er** | h**ow**, n**ow**, all**ow**, t**ow**n, d**ow**n, br**ow**n, cr**ow**d, **ow**l, t**ow**el, v**ow**el, p**ow**er, sh**ow**er, fl**ow**er, t**ow**er |
| **ou** in the **middle**, before most other consonants | h**ou**se, s**ou**th, m**ou**th, cl**ou**d, s**ou**nd, gr**ou**nd, acc**ou**nt, am**ou**nt, c**ou**ncil, c**ou**nty, ann**ou**nce, pron**ou**nce |
| **ow** can also be /əʊ/ | kn**ow**, sh**ow**, sl**ow**, wind**ow**, borr**ow**, tomorr**ow**, foll**ow**, narr**ow**, gr**ow**th |
| **ou** has many sounds | /ʌ/ c**ou**ntry, y**ou**ng, d**ou**ble, en**ou**gh, c**ou**sin · /ɜː/ j**ou**rney, j**ou**rnal · /uː/ gr**ou**p, s**ou**p, r**ou**te · /ɔː/ c**ou**rse, s**ou**rce, res**ou**rce, f**ou**r · /ʊ/ c**ou**ld, sh**ou**ld · /ʊə/ t**ou**r, t**ou**rist |
| ⚠️ **pronounce → pronunciation** | The noun **loses the o**: pro-**nun**-ci-a-tion |
