## [Day 3] -ABLE vs -IBLE

### Learning objectives

By the end of today you will be able to:

- spell **42 common -able / -ible adjectives**;
- use the **"whole word" test** to choose the ending;
- add the ending correctly: drop the **-e** (*value → valuable* ★), keep the **-e** (*notice → noticeable*), change **y → i** (*rely → reliable*), or double the consonant (*forget → forgettable*);
- build nouns (**-ability / -ibility**), adverbs (**-ably / -ibly**) and opposites (**un-, in-, im-, il-, ir-**).

### Pronunciation

> ⚠️ As a suffix, both **-able** and **-ible** are pronounced /əbl/: avail**able** /əˈveɪləbl/, poss**ible** /ˈpɒsəbl/. The word *able* on its own is /ˈeɪbl/, but you never hear that sound inside a longer word.

Some -able words also **lose a syllable in speech**, so you have to write letters you don't hear:

| Word | You hear | You write |
|---|---|---|
| comfortable | /ˈkʌmf-tə-bl/ (3 syllables) | com-**for**-ta-ble (4 syllables) |
| reasonable | /ˈriːz-nə-bl/ | rea-**so**-na-ble |
| valuable ★ | /ˈvæl-jə-bl/ | val-**u**-a-ble |
| vegetable | /ˈvedʒ-tə-bl/ | veg-**e**-ta-ble |

💡 **Say it slowly in your head as it is *spelt*:** *com-FOR-ta-ble*, *veg-E-ta-ble*.

### The 4 rules

**Rule 1: The whole-word test (works about 80% of the time).**
Cover the ending. If **a complete English word** is left, use **-able**. If what is left is **not a word**, use **-ible**.

| Whole word → -ABLE | Not a word → -IBLE |
|---|---|
| **comfort**able, **reason**able | **poss**ible (*poss* ✗) |
| **accept**able, **afford**able | **vis**ible (*vis* ✗) |
| **enjoy**able, **remark**able | **terr**ible, **horr**ible |
| **understand**able, **predict**able | **ed**ible, **aud**ible |
| **sustain**able, **renew**able | **feas**ible, **plaus**ible |
| **depend**able, **consider**able | **compat**ible, **tang**ible |

⚠️ **Exceptions, whole word + -ible:** access → access**ible**, flex → flex**ible**, sense → sens**ible**, reverse → revers**ible**, convert → convert**ible**, response → respons**ible**, resist → resist**ible**, digest → digest**ible**.

⚠️ **Exceptions, not a word + -able:** cap**able**, prob**able**, dur**able**, vulner**able**, inevit**able**, vi**able**.

**Rule 2: The noun test.** If the related noun ends in **-ation**, use **-able**. If it ends in **-ion** without the *a* (**-sion, -ssion, -tion**), use **-ible**.

| -ATION noun → -ABLE | -ION noun → -IBLE |
|---|---|
| toler**ation** → tolerable | vi**sion** → visible |
| applic**ation** → applicable | permi**ssion** → permissible |
| navig**ation** → navigable | divi**sion** → divisible |
| ador**ation** → adorable | comprehen**sion** → comprehensible |
| consider**ation** → considerable | conver**sion** → convertible |
| irrit**ation** → irritable | collec**tion** → collectible |

**Rule 3: Hard c/g → -able, soft c/g → -ible** (the same idea as Days 1 and 2).
appli**c**able, navi**g**able, ami**c**able (hard) · eli**g**ible, le**g**ible, tan**g**ible, invin**c**ible, for**c**ible (soft).
⚠️ To keep a soft sound before *-able*, English **keeps the e**: noti**ce**able, mana**ge**able, chan**ge**able, knowled**ge**able, repla**ce**able.

**Rule 4: When in doubt, choose -able.**
There are about **five times more -able words**, and **all new words use -able**: download**able**, recycl**able**, do**able**, like**able**.

### Spelling changes when you add -able / -ible

| Change | Rule | Examples |
|---|---|---|
| **Drop the silent e** | base ends in *-e* | valu**e** → valuable ★ · lov**e** → lovable · us**e** → usable · believ**e** → believable · desir**e** → desirable · measur**e** → measurable · revers**e** → reversible · sens**e** → sensible |
| **Keep the e** | after soft **ce / ge**, and after **ee** | noti**ce** → noticeable · mana**ge** → manageable · chan**ge** → changeable · knowled**ge** → knowledgeable · agr**ee** → agreeable |
| **y → i** | consonant + *y* | rel**y** → reliable · den**y** → deniable · var**y** → variable · justif**y** → justifiable · identif**y** → identifiable |
| **Keep the y** | vowel + *y* | enj**oy** → enjoyable · p**ay** → payable · empl**oy** → employable |
| **Double the consonant** | short stressed final syllable | forg**et** → forgettable · reg**ret** → regrettable · contr**ol** → controllable |
| ⚠️ **Trap** | stress moves to the front | pref**er** → **pre**ferable (one *r*) |

### Word families: nouns, adverbs and opposites

The letter (**a** or **i**) stays the same in the whole family.

| Adjective | Noun (-ity) | Adverb (-ly) | Opposite |
|---|---|---|---|
| available | avail**ability** | — | **un**available |
| reliable | reli**ability** | reli**ably** | **un**reliable |
| suitable | suit**ability** | suit**ably** | **un**suitable |
| sustainable | sustain**ability** | sustain**ably** | **un**sustainable |
| accountable | accountability ★ | — | **un**accountable |
| comfortable | — | comfort**ably** | **un**comfortable |
| acceptable | accept**ability** | accept**ably** | **un**acceptable |
| capable | cap**ability** | cap**ably** | **in**capable |
| responsible | responsibility ★ | respons**ibly** | **ir**responsible |
| possible | poss**ibility** | poss**ibly** | **im**possible |
| flexible | flex**ibility** | flex**ibly** | **in**flexible |
| accessible | access**ibility** | — | **in**accessible |
| visible | vis**ibility** | vis**ibly** | **in**visible |
| eligible | elig**ibility** | — | **in**eligible |
| legible | leg**ibility** | leg**ibly** | **il**legible |
| reversible | — | — | **ir**reversible |
| compatible | compat**ibility** | — | **in**compatible |

⚠️ **Prefixes can make double letters:** **il** + legible = i**ll**egible · **ir** + responsible = i**rr**esponsible · **ir** + reversible = i**rr**eversible · **im** + mature = i**mm**ature. Use **il-** before *l*, **ir-** before *r*, and **im-** before *p, b, m*.

### Common mistakes and corrections

| ❌ Wrong | ✅ Right | Why |
|---|---|---|
| availible | **available** | *avail* is a word → -able |
| responsable | **responsible** | respons(e) + ible: exception to Rule 1 |
| reposibility ★ | **responsibility** | re + **spons** + ibility (*response* is inside) |
| accesible | **accessible** | double *c*, double *s* |
| valueable ★ | **valuable** | drop the *e* of *value* |
| noticable | **noticeable** | keep the *e* to keep the *c* soft |
| knowledgable | **knowledgeable** | keep the *e*: knowledge + able |
| relyable | **reliable** | *y* → *i* |
| comfortible | **comfortable** | *comfort* is a word → -able |
| eligable | **eligible** | soft *g* → -ible |
| iresponsible | **irresponsible** | ir + responsible = **rr** |

### Memory techniques

- 💡 **Can it stand alone?** *Comfort, accept, afford, enjoy* can stand alone → **-able**. *Poss-, vis-, terr-* can't → **-ible**.
- 💡 **Soft E Keeps it Easy:** notic**e**able, manag**e**able. The *e* protects the soft sound.
- 💡 **valu-able** ★: the *e* in *value* goes before a vowel suffix.
- 💡 **re-SPONSE-ible:** *responsible* and *responsibility* ★ both contain *respons(e)*.
- 💡 **No clue? Choose -able.** It's five times more common.
- 💡 **ACCESSIBLE: two c's for the two Cars at the entrance, two s's for the two Steps.**
