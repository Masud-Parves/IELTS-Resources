# IELTS Resources

My IELTS preparation material: study guides, plans, model answers and practice sheets.
Target: Writing 7, Listening 7+, Speaking 6.5. Exam planned for December 2026.

> **Quick start on a phone:** open a folder below and tap any `.pdf` file. GitHub shows it in the browser.

## Not in this repo

This repository is public, so copyrighted books are **not** uploaded. These stay on my PC only:

- Cambridge IELTS 10–14 books and the category PDFs made from them
- Reading test passages saved from websites (`Passage 1/2/3`) and the sheets built from them
- Third-party eBooks (`Example/`, `Writing/eBook/`, `Speaking/eBook/`)

The full list is in [.gitignore](.gitignore).
